# CI/CD Tools and Practices Final Project

## Project Name
Node.js Counter Service - CI/CD Pipeline Implementation

## Overview
This repository contains the final project for the Coursera CI/CD Tools and Practices course. It features a Node.js sample application (Counter Service) configured with a complete Continuous Integration and Continuous Deployment (CI/CD) pipeline.

## Technologies Used
- **Node.js**: The core application framework.
- **GitHub Actions**: Handles the Continuous Integration (CI) by automatically installing dependencies, linting with ESLint, and running unit tests with Jest on every push and pull request.
- **Tekton & OpenShift**: Manages the Continuous Deployment (CD) pipeline, including environment cleanup, testing, building, and deploying the application to an OpenShift cluster.
